# 🐍 Snake & Ladder

A fun and interactive Snake & Ladder game created as a coding project. 🎲

## 🎮 About the Game

Snake & Ladder is a classic board game where players roll the dice, move across the board, climb ladders, and avoid snakes.

## ✨ Features

- 🎲 Dice rolling
- 🐍 Snakes
- 🪜 Ladders
- 🏆 Player winning system
- 🎮 Interactive gameplay
- 📊 Simple game logic
